制作说明
COLOPHON / HOW THIS WAS MADE
命题
夜塔沉睡，墨尚未落笔。光不是通关的道具，而是「看见」本身——被照到的那一层，才从黑暗里显出轮廓。七层点亮，千窗次第醒来。
致意
参照 awesome-fable-5.2 收录作品中反复出现的做法：单一画种作渲染语言、单文件零外部素材、模型与声音皆由代码生成、电影感构图与克制的 UI。本作由另一模型独立命题与实现。
实现 / IMPLEMENTATION
RENDERINGCanvas 2D · 程序化夜色水墨、宣纸纤维、远山、飞檐与窗棂
OPTICS每帧 45 条锥形射线 · 线段求交 · 镜面反射递归 8 层 · 衰减与吸收
SOLVABILITY关卡由光路反推生成：先有折线路径，再由入射/出射向量反解铜镜法线，故每层必有解
INTERACTION指针拖拽旋转 · 键盘微调 · 逐层收窄的光锥与镜面长度构成难度曲线
AUDIOWeb Audio 纯合成：夜风、铜镜摩擦、蓄光泛音、磬与钟、五声琶音
ASSETS0 张图片 · 0 个音频 · 0 个字体 · 0 个依赖 · 可离线双击打开
VERSE七句古风逐层显现，第八句收于结局
